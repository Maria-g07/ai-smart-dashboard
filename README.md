# 📊 AI Smart Sales Dashboard (Enterprise Edition)

> **📌 Σημείωση Portfolio:** Το παρόν έργο αποτελεί **ατομική εργασία (Personal Portfolio Project)**

Μια διαδραστική διαδικτυακή εφαρμογή Επιχειρηματικής Ευφυΐας (Business Intelligence) και Ανάλυσης Δεδομένων, σχεδιασμένη για την οπτικοποίηση πωλήσεων, την εξαγωγή αυτόματων επιχειρηματικών συμπερασμάτων και τη στατιστική πρόβλεψη μελλοντικών τάσεων.

---

## 🎯 Τι είναι αυτό το Project;
Το **AI Smart Sales Dashboard** μετατρέπει ακατέργαστα δεδομένα συναλλαγών λιανικής σε ένα δυναμικό περιβάλλον λήψης αποφάσεων. Αντί για στατικά υπολογιστικά φύλλα, προσφέρει άμεση εικόνα της οικονομικής απόδοσης μέσω διαδραστικών γραφημάτων, γεωγραφικής απεικόνισης, ενσωματωμένου βοηθού συνομιλίας (AI Chatbot) και μοντέλων πρόβλεψης πωλήσεων.

---

## ✨ Βασικές Λειτουργίες
* **📈 Βασικοί Δείκτες Απόδοσης (KPIs) & Σύγκριση Περιόδου (PoP):** Υπολογισμός συνολικού τζίρου, καθαρού κέρδους και πωληθεισών μονάδων με αυτόματη ποσοστιαία σύγκριση (`+` / `-`) σε σχέση με την προηγούμενη περίοδο.
* **🔍 Δυναμικό Φιλτράρισμα & Εύρος Ημερομηνιών:** Φιλτράρισμα σε πραγματικό χρόνο ανά χρονικό διάστημα, γεωγραφική περιοχή (Region), κατηγορία προϊόντος (Category) και τμήμα πελατών (Segment).
* **🗺️ Γεωγραφική & Κατηγορική Ανάλυση:** Διαδραστικός παγκόσμιος χάρτης διασποράς πωλήσεων, ραβδογράμματα ανά κατηγορία/πελάτη και χρονοσειρές ανά ημέρα, εβδομάδα, μήνα ή έτος.
* **💬 AI Sales Assistant (Sidebar Chatbot):** Ενσωματωμένος βοηθός συνομιλίας με φίλτρο συνάφειας (guardrails) που απαντά σε ερωτήσεις για κορυφαία προϊόντα, περιθώρια κέρδους και επιδόσεις.
* **🤖 Αυτόματα AI Insights & Recommendations:** Αλγοριθμική εξαγωγή συμπερασμάτων και στρατηγικών προτάσεων για διαχείριση αποθεμάτων και στόχευση πελατών.
* **🎯 Μήτρα Κερδοφορίας (Scatter Matrix):** Ανάλυση σχέσης τζίρου και καθαρού κέρδους ανά προϊόν για τον εντοπισμό ζημιογόνων κωδικών.
* **🔮 Προβλέψεις AI (Linear Regression Forecasting):** Πρόβλεψη τάσης πωλήσεων 5 μηνών με χρήση γραμμικής παλινδρόμησης και απεικόνιση ζωνών εμπιστοσύνης 95% (Best/Worst Case).
* **🌓 Προσαρμογή Εμφάνισης (UI Styling):** Υποστήριξη **Light Mode** και **Dark Mode** στα γραφήματα, καθώς και custom CSS styling για επαγγελματική αισθητική.

## 🏗️ Δομή & Αρχιτεκτονική Συστήματος
Η εφαρμογή ακολουθεί μια αρθρωτή (modular) ροή επεξεργασίας δεδομένων σε 4 επίπεδα:
1. **Data Ingestion & Caching Layer (`load_data`):** Άντληση δεδομένων από απομακρυσμένη πηγή CSV, καθαρισμός στηλών, μετατροπή τύπων δεδομένων και αποθήκευση στη μνήμη (`@st.cache_data`) για μέγιστη ταχύτητα.
2. **Filtering & State Management Layer:** Διαχείριση των επιλογών του χρήστη από το Sidebar και διατήρηση ιστορικού συνομιλίας μέσω `st.session_state`.
3. **Analytics & ML Engine:** Επεξεργασία υποσυνόλων δεδομένων με `Pandas` και εφαρμογή πολυωνυμικής προσαρμογής 1ου βαθμού (`NumPy polyfit`) για υπολογισμό τάσεων και τυπικού σφάλματος.
4. **Presentation Layer (UI/UX):** Απεικόνιση σε δύο οργανωμένες καρτέλες (Tabs) μέσω `Streamlit` και `Plotly`.

```text
ai-smart-dashboard/
├── app.py              # Κύριος κώδικας της εφαρμογής, UI, λογική AI & γραφήματα
├── requirements.txt    # Λίστα απαραίτητων βιβλιοθηκών Python
└── README.md           # Τεκμηρίωση του έργου
```

## 🚀 Οδηγίες Εγκατάστασης & Εκτέλεσης

Ακολουθήστε τα παρακάτω βήματα για να τρέξετε την εφαρμογή τοπικά στον υπολογιστή σας:

### 1. Λήψη του αποθετηρίου (Clone)
```bash
git clone https://github.com<your-username>/ai-smart-dashboard.git
cd ai-smart-dashboard
```

### 2. Δημιουργία Εικονικού Περιβάλλοντος (Προαιρετικό αλλά προτείνεται)
```bash
python -m venv .venv
# Σε Windows:
.venv\Scripts\activate
# Σε Mac/Linux:
source .venv/bin/activate
```

### 3. Εγκατάσταση Βιβλιοθηκών
```bash
pip install -r requirements.txt
```

### 4. Εκκίνηση της Εφαρμογής
```bash
streamlit run app.py
```
Η εφαρμογή θα ανοίξει αυτόματα στον φυλλομετρητή σας στη διεύθυνση `http://localhost:8501`.
